# 👋 Hey, I'm Geet.

Software engineer with an M.Sc. in Statistics, building full-stack and AI-powered applications with Python, Django, React, and REST APIs. I like turning messy business problems — trading data, ERP workflows, natural-language questions over datasets — into working, deployed software.

---

## 🚧 Currently building

- **AnalystAI** — an AI-assisted analytics platform for natural-language querying over structured business datasets and unstructured documents, using RAG and query routing (Django REST Framework + React + PostgreSQL)
- **ERP** — a multi-business management system covering inventory, sales, customers, suppliers, finance, and reporting (React + Django REST Framework + PostgreSQL)
- **QuantMachine** — a trading and portfolio-management platform with challenge portfolios, trade tracking, and CSV-based data ingestion (Python + Django + React)
